# UPSC Prelims A2Z Sheet

Striver made one for DSA. This one is for UPSC.

A topic-by-topic progress tracker for UPSC Civil Services Preliminary Examination — covering GS Paper 1 and CSAT in full. No login, no backend, no fluff. Just you, the syllabus, and checkboxes.

---

## Why this exists

Every UPSC aspirant has a syllabus PDF they downloaded once and never opened again. This turns that PDF into something you can actually interact with — check off topics as you finish them, see how much of Laxmikanth you've actually covered, and stop lying to yourself about being "almost done" with Geography.

## How it works

- Check a topic → it's marked done, row turns green, progress updates instantly
- Progress is saved in your browser's localStorage — closes, refreshes, restarts: still there
- "Mark All as Done" per section for topics you've already covered
- Reset button if you want to start fresh (asks for confirmation, not a trap)
- Works offline after first load

---

## Stack

Single HTML file. No framework, no build step, no node_modules folder with 47,000 packages. HTML + CSS + vanilla JS + localStorage. That's it.

To run locally: double-click the file.
To deploy: drag it onto Netlify.
